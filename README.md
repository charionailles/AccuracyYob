## Info about AccuracyYob

AccuracyYob, as it shall be named, is an attempt by myself (not a C++ developer) 
to modernize the ageing codebase of GameYob-5.2 to C++23 (or 26), while also 
increasing its emulation accuracy through rigorous testing based upon results 
gathered from my own Gameboy Color.

## Info about AccuracyYob Branches

The Master branch of this repository will be based upon GameYob-5.2, as that is 
the last stable release of GameYob prior to the developer disappearing. All
other branches are kept solely for reference and archiving purposes.
